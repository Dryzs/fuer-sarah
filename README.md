# Für Sarah

Fertige statische Geburtstagsseite für GitHub Pages.

1. Öffentliches Repository `fuer-sarah` erstellen.
2. Den Inhalt dieses Ordners hochladen: `index.html` und `assets` müssen direkt im Repository liegen.
3. Settings → Pages → Deploy from a branch → main → / (root) → Save.
4. Die von GitHub unter Pages angezeigte Website-Adresse öffnen.

Die ZIP-Datei selbst nicht ins Repository hochladen, sondern vorher entpacken.
Alle Fotos, Videos, Schriften und Animationen sind enthalten.
Die Dateien und Medien sind in einem öffentlichen Repository öffentlich sichtbar.
